## 项目概述

**Stitcher** 是一个基于 **Vue 3 + TypeScript** 的可视化页面构建器/低代码编辑器项目，支持多UI库（Element Plus、Ant Design、Naive UI）。

### 技术栈
- **前端框架**：Vue 3 + TypeScript
- **构建工具**：Vite
- **状态管理**：Pinia
- **路由系统**：Vue Router
- **UI库**：shadcn-vue/ui + Element Plus + Ant Design + Naive UI
- **样式系统**：Tailwind CSS
- **测试**：Vitest + Playwright
