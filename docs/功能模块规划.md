# 低代码平台功能模块规划

## 1. 功能模块概览

根据设计稿分析，低代码平台包含以下核心功能模块：

```
┌─────────────────────────────────────────────────────────────┐
│                      功能模块分布                             │
├─────────────────┬─────────────────┬─────────────────────────┤
│   左侧边栏模块    │    主工作区模块    │      右侧边栏模块        │
├─────────────────┼─────────────────┼─────────────────────────┤
│  • 组件库       │  • 画布编辑     │  • 属性配置             │
│  • 页面管理     │  • 拖拽系统     │  • 样式设置             │
│  • 数据源       │  • 网格系统     │  • 事件绑定             │
│  • 工作流       │  • 缩放平移     │  • 高级选项             │
│  • 设置         │  • 选区管理     │                        │
└─────────────────┴─────────────────┴─────────────────────────┘
                        │
┌─────────────────────────────────────────────────────────────┐
│                      头部工具栏模块                           │
├─────────────────────────────────────────────────────────────┤
│ 撤销/重做  │  响应式切换  │  保存  │  预览  │  发布  │  用户   │
└─────────────────────────────────────────────────────────────┘
```

## 2. 详细功能规划

### 2.1 头部工具栏模块 (TopBar)

#### 2.1.1 撤销/重做功能
- **功能描述**: 支持操作历史记录的撤销和重做
- **技术实现**:
  - Command模式实现
  - 快照机制存储状态
  - 最大记录数: 100步
- **用户操作**:
  - 点击撤销按钮 或 Ctrl+Z
  - 点击重做按钮 或 Ctrl+Y
- **状态管理**: `useHistoryStore`
- **文件位置**: `src/modules/editor/components/TopBar.vue`

#### 2.1.2 响应式尺寸切换
- **功能描述**: 提供桌面、平板、手机三种预览尺寸
- **尺寸规格**:
  - 桌面: 1920x1080 (默认)
  - 平板: 768x1024
  - 手机: 375x667
- **技术实现**:
  - 动态调整画布容器尺寸
  - CSS媒体查询适配
  - 实时缩放计算
- **交互效果**:
  - 选中状态高亮
  - 悬停预览效果
- **状态管理**: `useCanvasStore.device`
- **文件位置**: `src/modules/editor/components/TopBar.vue`

#### 2.1.3 保存功能
- **功能描述**: 将当前项目保存到本地存储
- **保存内容**:
  - 项目基本信息
  - 页面组件树
  - 组件属性配置
  - 样式设置
  - 事件绑定
- **技术实现**:
  - LocalStorage存储
  - IndexedDB大数据存储
  - 增量保存机制
- **文件格式**: JSON
- **状态管理**: `useProjectStore`
- **文件位置**: `src/modules/editor/services/saveService.ts`

#### 2.1.4 预览功能
- **功能描述**: 在新窗口中预览生成的代码
- **预览方式**:
  - 弹出新窗口
  - iframe嵌入
  - 全屏预览
- **技术实现**:
  - 动态代码生成
  - postMessage通信
  - 热更新机制
- **文件位置**: `src/modules/preview/services/previewService.ts`

#### 2.1.5 发布功能
- **功能描述**: 将项目打包并部署到服务器
- **输出内容**:
  - Vue单文件组件
  - 静态资源文件
  - 依赖配置文件
- **部署方式**:
  - 下载ZIP包
  - 直接部署（可选）
  - 代码复制
- **文件位置**: `src/modules/code-generator/services/exportService.ts`

### 2.2 左侧边栏模块 (LeftSidebar)

#### 2.2.1 Workspace管理
- **功能描述**: 管理当前工作空间信息
- **显示内容**:
  - Workspace头像
  - 项目名称
  - 项目描述
  - 最近修改时间
- **操作功能**:
  - 新建项目
  - 打开项目
  - 项目设置
- **文件位置**: `src/modules/editor/components/LeftSidebar.vue`

#### 2.2.2 组件库 (Components)
- **功能描述**: 展示所有可拖拽的UI组件
- **组件分类**:
  1. **基础组件**
     - Button 按钮
     - Input 输入框
     - Text 文本
     - Image 图片
     - Link 链接
  2. **布局组件**
     - Container 容器
     - Row 行
     - Col 列
     - Divider 分割线
     - Space 间距
  3. **导航组件**
     - Menu 菜单
     - Breadcrumb 面包屑
     - Pagination 分页
     - Tabs 标签页
  4. **数据录入**
     - Radio 单选
     - Checkbox 多选
     - Select 选择器
     - Switch 开关
     - DatePicker 日期选择器
     - TimePicker 时间选择器
  5. **数据展示**
     - Table 表格
     - List 列表
     - Card 卡片
     - Descriptions 描述列表
     - Tag 标签
     - Progress 进度条
  6. **反馈组件**
     - Message 消息提示
     - Modal 对话框
     - Drawer 抽屉
     - Popover 气泡卡片
     - Tooltip 文字提示
  7. **业务组件**
     - Form 表单
     - Search 搜索
     - Upload 上传

- **UI库支持**:
  - Element Plus (默认)
  - Ant Design Vue
  - Naive UI

- **组件元数据**:
```typescript
interface ComponentMeta {
  id: string
  name: string
  icon: string

  thumbnail: string
  defaultProps: Record<string, any>
  propTypes: PropSchema[]
  events: EventSchema[]
  styles: StyleSchema[]
}
```

- **文件位置**:
  - `src/modules/component-library/data/components.ts`
  - `src/modules/component-library/components/ComponentPanel.vue`

### 2.3 主工作区模块 (MainCanvas)

#### 2.3.1 画布编辑
- **功能描述**: 核心的可视化编辑区域
- **核心功能**:
  1. **网格系统**
     - 网格大小: 8px
     - 显示/隐藏切换
     - 吸附对齐功能
  2. **画布操作**
     - 缩放: 25% - 200%
     - 平移: 拖拽画布
     - 适应屏幕
     - 实际尺寸
  3. **辅助线**
     - 智能辅助线
     - 对齐提示
     - 距离提示

- **技术实现**:
  - Canvas/SVG渲染
  - 虚拟化技术
  - 命中测试算法
  - 冲突检测

- **文件位置**: `src/modules/canvas/components/Canvas.vue`

#### 2.3.2 拖拽系统
- **功能描述**: 组件拖拽放置的核心功能
- **拖拽类型**:
  1. **从组件库拖拽到画布**
     - 拖拽开始：显示组件预览
     - 拖拽中：跟随鼠标移动
     - 放置：创建组件实例
  2. **画布内拖拽排序**
     - 兄弟节点排序
     - 嵌套容器放置
     - 位置交换
  3. **调整大小和位置**
     - 手动拖拽
     - 键盘微调
     - 属性面板精确输入

- **技术实现**:
  - **核心库**: interact.js
  - **实现要点**:
    - 使用 `interact.js` 统一处理“从组件库拖入”和“在画布内操作”的全部交互。
    - 通过 `draggable` 和 `resizable` 实现组件的自由移动和缩放。
    - 通过 `dropzone` 实现画布的放置功能。
    - 利用 `modifiers` 实现网格吸附和智能辅助线。

- **文件位置**: `src/modules/drag/services/dragService.ts`

#### 2.3.3 选区管理
- **功能描述**: 管理当前选中的组件
- **选区操作**:
  - 单选: 点击组件
  - 多选: Ctrl+点击
  - 框选: 拖拽选框
  - 全选: Ctrl+A
  - 取消选择: 点击空白处
- **选区反馈**:
  - 选中边框高亮
  - 控制手柄显示
  - 组件信息提示
- **文件位置**: `src/modules/canvas/components/SelectionManager.vue`

#### 2.3.4 组件树
- **功能描述**: 以树形结构展示页面组件层级
- **操作功能**:
  - 展开/折叠
  - 节点重命名
  - 拖拽排序
  - 快速定位
  - 隐藏/显示切换
- **文件位置**: `src/modules/canvas/components/ComponentTree.vue`

## 3. 核心流程设计

### 3.1 新建项目流程
```
开始 → 选择UI库 → 设置项目信息 → 进入编辑器 → 初始化画布 → 完成
```

### 3.2 拖拽组件流程
```
点击组件 → 开始拖拽 → 拖拽至画布 → 放置位置检测 → 创建组件实例 → 显示控制框 → 更新组件树 → 记录历史
```

### 3.3 代码生成流程
```
获取组件树 → 解析组件配置 → 生成模板代码 → 生成样式代码 → 生成事件代码 → 打包输出 → 预览/发布
```

### 3.4 保存项目流程
```
收集项目数据 → 序列化组件树 → 存储到本地 → 显示保存成功 → 更新项目状态
```

## 4. 数据流设计

### 4.1 状态管理
- **Pinia Store设计**:
  - `useEditorStore`: 编辑器整体状态
  - `useCanvasStore`: 画布状态
  - `useComponentStore`: 组件库状态
  - `usePropertyStore`: 属性面板状态
  - `useProjectStore`: 项目数据
  - `useHistoryStore`: 历史记录

### 4.2 事件流
```
用户操作 → 触发事件 → 更新Store → 触发响应 → 渲染界面
```

### 4.3 数据同步
- 组件拖拽 → 更新组件树 → 刷新画布
- 属性修改 → 更新组件配置 → 刷新组件显示
- 样式调整 → 更新样式对象 → 刷新样式

## 5. 性能指标

### 5.1 响应时间指标
- 组件拖拽延迟: < 16ms (60fps)
- 属性面板更新: < 100ms
- 代码生成: < 1s (100个组件)
- 画布缩放/平移: < 16ms

### 5.2 资源占用指标
- 内存占用: < 500MB
- 本地存储: < 50MB/项目
- CPU占用: < 30% (常规操作)

### 5.3 兼容性指标
- 浏览器支持: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- 分辨率支持: 1920x1080及以上
- 设备适配: 桌面优先，支持平板和手机预览
