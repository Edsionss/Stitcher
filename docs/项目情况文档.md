# Stitcher 低代码平台 - 项目情况文档

## 项目概览

**项目名称**: Stitcher 低代码平台
**项目类型**: Vue 3 + TypeScript 低代码/无代码开发平台
**开发时间**: 2025年11月
**当前状态**: 基础架构搭建阶段（阶段一）

## 项目背景

Stitcher 是一个现代化的低代码平台，旨在通过拖拽式界面帮助开发者快速构建 Vue 3 应用程序。项目采用 Vue 3 + TypeScript + Vite 技术栈，集成多个主流 UI 库（Element Plus、Ant Design、Naive UI），提供可视化的页面设计和代码生成能力。

## 技术架构

### 核心技术栈

- **前端框架**: Vue 3.5.22 (Composition API)
- **开发语言**: TypeScript 5.9.0
- **构建工具**: Vite 7.1.11
- **路由管理**: Vue Router 4.6.3
- **状态管理**: Pinia 3.0.3
- **样式方案**: Tailwind CSS 4.1.17 + SCSS
- **UI组件库**:
  - shadcn-vue (编辑器 UI)
  - Element Plus 2.11.7
  - Ant Design Vue 4.2.6
  - Naive UI 2.43.1
- **拖拽库**: vue-draggable-plus 0.6.0

### 开发工具

- **代码规范**: ESLint 9.37.0 + Prettier 3.6.2
- **测试框架**:
  - Vitest 3.2.4 (单元测试)
  - Playwright 1.56.1 (E2E 测试)
- **包管理器**: pnpm

## 核心功能模块

### 1. 状态管理系统 (Pinia Stores)

#### 1.1 Editor Store (`src/stores/editor.ts`)
- 管理当前项目和页面
- 处理组件选择状态
- 跟踪编辑状态（脏标记）

#### 1.2 Canvas Store (`src/stores/canvas.ts`)
- 画布缩放控制
- 设备类型切换（桌面/平板/手机）
- 网格系统配置
- 辅助线系统

#### 1.3 Component Store (`src/stores/component.ts`)
- 组件注册和管理
- 组件树结构维护
- 组件属性映射

#### 1.4 Property Store (`src/stores/property.ts`)
- 属性面板状态
- 当前选中组件属性
- 动态属性编辑器

#### 1.5 Project Store (`src/stores/project.ts`)
- 项目元数据管理
- 项目保存/加载
- 数据持久化

#### 1.6 History Store (`src/stores/history.ts`) ✅ 已实现
- 撤销/重做功能实现
- 操作历史记录
- 最大历史记录数: 100
- 支持操作类型: add/delete/update/move

### 2. UI 适配系统 (Adapters)
