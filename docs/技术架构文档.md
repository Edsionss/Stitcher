# 低代码平台技术架构文档

## 1. 项目概述

### 1.1 项目背景
低代码平台是一个基于Vue3 + TypeScript构建的可视化拖拽式应用开发平台，支持Element Plus、Ant Design和Naive UI三个主流UI组件库，通过拖拽方式快速构建页面，实现代码生成、预览和发布功能。

### 1.2 技术栈
- **前端框架**: Vue 3.5.22
- **开发语言**: TypeScript 5.9.0
- **构建工具**: Vite 7.1.11
- **路由管理**: Vue Router 4.6.3
- **状态管理**: Pinia 3.0.3

- **编辑器UI库**（平台自身界面）:
  - shadcn-vue（基于Radix UI + Tailwind CSS）

- **生成代码支持的UI库**:
  - Element Plus（默认）
  - Ant Design Vue
  - Naive UI

- **拖拽引擎**: vue-draggable-plus
- **代码编辑器**: Monaco Editor
- **代码生成**: 基于AST抽象语法树
- **样式方案**:
  - Tailwind CSS (与shadcn-vue结合使用)
  - SCSS (支持原生SCSS语法)
  - CSS3 + Scoped CSS

### 2.2 核心模块划分

#### 2.2.1 编辑器模块 (Editor Module)
- **位置**: `src/modules/editor/`
- **职责**: 主编辑器界面的整体布局和状态管理
- **组件**:
  - EditorContainer: 主容器
  - TopBar: 顶部工具栏
  - LeftSidebar: 左侧导航栏
  - RightPanel: 右侧属性面板
  - Canvas: 画布区域

#### 2.2.2 画布模块 (Canvas Module)
- **位置**: `src/modules/canvas/`
- **职责**: 可视化编辑区域，支持组件拖拽、定位、缩放
- **组件**:
  - Canvas: 主画布
  - CanvasNode: 画布节点
  - Selection: 选区管理
  - Grid: 网格系统

#### 2.2.3 组件库模块 (Component Library Module)
- **位置**: `src/modules/component-library/`
- **职责**: 管理所有可拖拽的组件
- **功能**:
  - Element Plus组件适配
  - Ant Design组件适配
  - 自定义组件注册
  - 组件缩略图生成

#### 2.2.4 拖拽模块 (Drag Module)
- **位置**: `src/modules/drag/`
- **职责**: 处理组件拖拽逻辑
- **功能**:
  - 拖拽开始/进行/结束事件处理
  - 放置区域检测
  - 拖拽反馈动画
  - 撤销/重做支持

#### 2.2.5 属性面板模块 (Property Panel Module)
- **位置**: `src/modules/property-panel/`
- **职责**: 动态渲染选中组件的属性配置
- **功能**:
  - 属性编辑器
  - 样式编辑器
  - 事件绑定
  - 高级设置

#### 2.2.6 代码生成模块 (Code Generator Module)
- **位置**: `src/modules/code-generator/`
- **职责**: 将设计数据转换为Vue代码
- **功能**:
  - 模板生成
  - 样式生成
  - 事件代码生成
  - 依赖管理

#### 2.2.7 预览模块 (Preview Module)
- **位置**: `src/modules/preview/`
- **职责**: 实时预览生成的代码
- **功能**:
  - 独立预览窗口
  - 热更新
  - 响应式测试
  - 交互测试

#### 2.2.8 数据管理模块 (Data Module)
- **位置**: `src/stores/`
- **职责**: 全局状态管理
- **Store**:
  - useEditorStore: 编辑器状态
  - useComponentStore: 组件库状态
  - useProjectStore: 项目数据
  - useHistoryStore: 历史记录

## 4. 核心技术方案

### 4.1 拖拽实现方案
- **技术选型**: vue-draggable-plus + 自定义拖拽逻辑
- **文档参考**: https://vue-draggable-plus.pages.dev/guide/
- **实现要点**:
  - 使用vue-draggable-plus核心能力
  - 支持多方向拖拽
  - 虚拟画布提升性能
  - 吸附网格系统
  - 碰撞检测算法

### 4.2 代码生成方案
- **技术选型**: AST抽象语法树
- **生成流程**:
  1. 设计数据解析
  2. 组件树构建
  3. 模板字符串生成
  4. 样式对象转换
  5. 事件代码生成

### 4.3 响应式预览方案
- **技术选型**: iframe沙箱 + postMessage通信
- **实现要点**:
  - 独立渲染进程
  - 实时代码更新
  - 事件桥接
  - 错误隔离

### 4.4 多UI库适配方案
- **策略**: 统一组件接口 + 适配器模式
- **实现**:
  ```typescript
  interface ComponentAdapter {
    library: string
    componentMap: Map<string, ComponentConfig>
  }
  ```

### 4.5 样式系统方案
- **编辑器样式**:
  - **Tailwind CSS**: 原子化CSS框架，与shadcn-vue深度结合
  - **文档参考**: https://tailwindcss.com/docs/installation/using-vite
  - **SCSS**: 支持原生SCSS语法，用于复杂样式场景
  - **主题系统**: 基于Tailwind CSS的主题定制能力

- **生成代码样式**:
  - 保持与UI库原生样式一致
  - Element Plus: 使用其默认样式 + 自定义主题
  - Ant Design: 使用Less样式系统
  - Naive UI: 使用CSS变量主题系统

- **样式生成策略**:
  - Scoped CSS: 组件样式隔离
  - CSS-in-JS: 动态样式支持
  - 响应式样式: 基于Tailwind响应式断点
  - 自定义CSS: 支持用户自定义样式

- **配置要点**:
  - Tailwind配置与shadcn-vue主题保持一致
  - SCSS模块化组织
  - 样式变量统一管理
  - 按需引入减少包体积

## 6. 开发规范

### 6.1 目录结构规范
```
src/
├── modules/           # 功能模块
│   ├── editor/       # 编辑器模块
│   ├── canvas/       # 画布模块
│   ├── component-library/  # 组件库
│   ├── property-panel/     # 属性面板
│   ├── code-generator/     # 代码生成
│   └── preview/      # 预览模块
├── components/       # 公共组件
├── styles/          # 样式文件
│   ├── tailwind/    # Tailwind配置
│   ├── scss/        # SCSS文件
│   ├── variables/   # 样式变量
│   └── mixins/      # SCSS混入
├── stores/          # Pinia状态
├── utils/           # 工具函数
├── types/           # 类型定义
└── config/          # 配置文件
```

### 6.2 组件开发规范
- 使用`<script setup>`语法
- 遵循Vue 3组合式API
- Props类型定义完整
- 事件命名使用kebab-case

### 6.3 样式开发规范
- **Tailwind CSS**:
  - 优先使用Tailwind原子类
  - 遵循Tailwind命名规范
  - 自定义配置在tailwind.config.js中
  - 避免在组件中写内联样式
- **SCSS**:
  - 使用SCSS嵌套语法
  - 变量命名使用$开头，kebab-case风格
  - 混入(mixins)复用复杂样式
  - 避免过深层级嵌套（建议≤3层）
- **样式组织**:
  - 全局样式在styles目录
  - 组件样式使用<style scoped>
  - 公共样式提取到mixins
  - 样式变量统一管理
- **响应式设计**:
  - 使用Tailwind响应式前缀
  - 移动端优先原则
  - 统一断点定义

### 6.4 代码风格规范
- 启用ESLint + Prettier
- TypeScript严格模式
- 注释覆盖率>40%
- 函数复杂度<10
